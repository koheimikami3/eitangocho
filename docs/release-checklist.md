# リリース前 手動 QA チェックリスト

新バージョンを Mac App Store に提出する前に、`flutter run -d macos`(または
リリースビルドの `.app`)で毎回ひととおり確認する回帰テスト項目。
自動テスト(`flutter test`)でカバーできない実機挙動・UI・キーボード操作を対象とする。

> 使い方: 提出前にこのリストを上から実行する。UI の見た目は実装済みアプリと
> [app_colors.dart](../lib/constants/app_colors.dart) / [app_dimensions.dart](../lib/constants/app_dimensions.dart)
> のトークンが基準。機能仕様は [design.md](design.md)。
> 提出手順そのものは [app-store-submission.md](app-store-submission.md)。

## 自動チェック(提出ビルド前に必須)

- [ ] `flutter analyze` でエラー・警告なし
- [ ] `flutter test` で全テストパス
- [ ] `dart run build_runner build --delete-conflicting-outputs` 後に差分がない(生成物が最新)

## JSON エクスポート/インポート

- [ ] 設定「データ」セクションからエクスポートダイアログが開き、保存すると SnackBar が出る
- [ ] 書き出した JSON のフォーマットが正しい(`version`, `exportedAt`, `words` 配列。`id` を含まない)
- [ ] マージ規則: 古いファイルをインポートしても新しい `updatedAt` の行は上書きされない
- [ ] マージ規則: 削除済み単語を含む旧ファイルをインポートすると「追加」として復活する
- [ ] マージ規則: `updatedAt` を新しくした行は「更新」に計上され内容が反映される
- [ ] マージキーは `word`(trim + lowercase)。表記を変えた行は別単語として両方残る(リネーム不可・想定通り)
- [ ] 壊れた JSON / 未知バージョン(`"version": 2` 等)はエラーダイアログが出る
- [ ] ファイルダイアログをキャンセルしても何も起きない

## キーボードショートカット

- [ ] ⌘N: どのビューからでも登録ビューへ切り替わる(フォーム入力中でも文字入力を妨げない)
- [ ] ⌘F: 学習中・全単語ビューで検索フィールドにフォーカス。検索欄の無いビューでは無反応
- [ ] クイズ中 Space / Enter で答えが開示される
- [ ] 開示後 ← または 1 で「忘れていた」、→ または 2 で「覚えている」。開示前は無反応
- [ ] クイズ → 別ビュー → クイズ再入場でキーが再び効く(フォーカス再取得)
- [ ] 干渉なし: 検索欄・登録フォーム・編集ダイアログ・DeepL キー欄で Space/Enter/1/2/矢印が普通に入力できる
- [ ] Esc で編集・削除確認・インポート結果の各ダイアログが閉じる

## 各画面の目視(空状態・データあり・ホバー/フォーカス)

- [ ] 学習中カードビュー(空状態・カード・訳の表示トグル・学習済みチェック・ホバー・出現アニメ)
- [ ] 全単語テーブル(検索・学習済みチェック・行ホバー・狭幅時の横スクロールフォールバック)
- [ ] フラッシュクイズ(空状態・出題中の表面/裏面・完了画面・「忘れていた単語」一覧)
- [ ] 単語登録(Step1 入力・自動入力ボタン・Step2 確認フォーム・辞書未収録時の警告バナー)
- [ ] 設定画面(クイズ方向・IPA 表示・表示サイズスライダー・DeepL キー欄・データセクション)
- [ ] 各ダイアログ(編集・削除確認・インポート結果・インポートエラー・右クリックメニュー)

## 表示サイズ(uiScale)別の崩れ

- [ ] uiScale = 1.0(最小)・小さいウィンドウで各画面が溢れない
- [ ] uiScale = 2.0(最大)・小さいウィンドウで各画面が溢れない(全単語テーブルは横スクロールに退避)

## リリースビルドの実機確認

- [ ] `flutter build macos --release` が成功する
- [ ] `--dart-define=ENABLE_AI=true` を付けていない(AI コードをストア配布に含めない)
- [ ] リリース `.app` を直接起動し、サンドボックス(sandbox + network.client +
      user-selected.read-write)下で以下が動く:
  - [ ] 単語登録 → 自動入力(Free Dictionary / EJDict / DeepL)
  - [ ] 発音再生
  - [ ] クイズ一連 + キーボードショートカット
  - [ ] エクスポート → インポート
  - [ ] 設定の保存・再起動後の復元
- [ ] `/Applications/` へコピーして Launchpad から起動できる
- [ ] `pubspec.yaml` の `version` を更新済み(前回提出よりビルド番号 +N を必ず上げる)

> 補足: `flutter run`(debug)は Bundle ID が `...eitangocho.dev`・表示名「シンプル英単語帳(Dev)」で、
> ストア配布版とは別のサンドボックスコンテナ(別 DB)。本番データの確認は必ずリリース `.app` 側で行う。
