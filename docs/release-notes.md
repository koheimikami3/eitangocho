# リリースノート

App Store / Mac App Store の「このバージョンの新機能」に掲載した文面を、そのまま記録する。
**提出のたびにここへ追記すること。** ストア側の文面は後から遡って読むのが手間なため、
リポジトリ内に控えを持つ。

書き方の決まり:

- 「〜しました。」の短い行を並べる。1 行 1 項目で、2〜4 行に収める
- **内部の仕組みには触れない**。データソース名(kaikki / Tatoeba / EJDict)や
  クラス名は書かず、利用者から見て何が変わったかだけを書く
- **iOS と macOS で入った内容が違うときは文面を分ける**。同じなら同じ文面でよい
  (1.3.0 は共通、1.2.0 と 1.4.0 は別文面)
- 半角英数の前後には空白を入れる(`Mac と iPhone`、`iPhone 版`)
- ビルド番号は全履歴を通じて単調増加。理由と提出手順は [design.md](design.md) を参照

学習中カードの表示を調整しました。
アプリ内に広告を表示するようになりました。
```

### macOS

```
句動詞の登録に対応しました。
例文と入力欄の使い勝手を改善しました。
```

英字キーボードの固定は iOS のみ(macOS は OS の入力方式を制御できない)、学習中カードの
調整と広告も iOS のみのため、macOS の文面からは外している。

```

### macOS

```

```

macOS 側の文面が iCloud 同期になっているのは、Mac App Store のバージョン履歴に
1.1.0 が無く、この内容が 1.2.0 として掲載されているため(design.md では
1.1.0 = iCloud 同期対応として記録している)。**掲載済みの文面をそのまま写しているので、
食い違いはストア側の履歴が正**。
