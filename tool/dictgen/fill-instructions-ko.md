# 事前生成辞書: 韓国語の訳の生成の指示

英単語帳アプリの自動入力に使う辞書に、韓国語の訳を足す。辞書には語ごとの品詞・英例文と日本語・繁体字の訳が
既にあり、変えない。語ごとに韓国語の `meaning`(単語の訳)と `exampleTranslation`(英例文の訳)だけを作り、
指定の JSON で出力する。IPA・品詞・英例文は作らない。

利用者は韓国語の話者で、中学〜大学入試、TOEIC あたりの英語を学んでいる。韓国の標準語で書く。
カードには見出し語・訳・英例文・例文の訳が並ぶ。

## 入力

```json
{
  "word": "happy",
  "partsOfSpeech": ["adjective"],
  "exampleEn": "My grandmother was happy to see us at dinner.",
  "ja": "うれしい,幸せな / 満足した / めでたい",
  "zhHant": "高興 / 幸福 / 滿意 / 喜慶",
  "kaikkiKo": [{ "pos": "adj", "word": "행복하다", "sense": "contented, joyous" }]
}
```

- `partsOfSpeech`・`exampleEn`・`ja`・`zhHant` は確定した値。訳の先頭の意味と語義の範囲をそろえるのに使う
- `kaikkiKo` は Wiktionary の韓国語の訳語で、`sense` は語義の英語の説明。**材料であって正解ではない**。
  語が少なく、形も不ぞろいで(形容詞が `행복하다` など)、空の語も多い。空でもふつうに訳を書く

## 訳(`meaning`)

- **先頭の意味は `ja`・`zhHant` の先頭にそろえる**。例文は言語間で 1 つを共有していて、その意味で使われているため
- **語義の範囲は `ja` を目安にする**。`ja` の語義に順に対応させ、`ja` に無い意味は足さない。
  韓国語で同じ語になる語義は 1 つにまとめるので、数が `ja` より少なくてもよい
- 語義(` / ` 区切りの単位)は 1〜7 個。1 つの語義の中は訳語を 1〜3 個、`, ` で区切る
  (例: `issue` → `문제, 쟁점 / 발행 / (잡지의) 호 / 발행하다`)
- 品詞ごとに形をそろえる。`kaikkiKo` の形に引きずられない
  - 名詞・副詞: そのまま(`문제`、`항상`)
  - 動詞: 基本形(`포기하다`)。句動詞も同じ(`give up` → `포기하다`)
  - 形容詞: 連体形(`행복한`、`비싼`、`조용한`)。`행복하다` の形にしない
- いちばん基本の訳語を外さない。硬い語・漢語だけに置き換えない(例: `buy` は `사다`。`구매하다` だけにしない)。
  訳語は語にする。説明的な句にしない(例: `bank` は `은행`)
- 熟語は句全体の意味を訳す。1 語にならなければ短い句でよい(例: `break the ice` → `어색한 분위기를 깨다`)。
  `ja` の「人」「物」は `남`・`무언가` で書く(例: `get off someone's back` → `남을 그만 괴롭히다`)。形は句全体の働きの品詞に合わせる
- 活用形の見出し(`teeth`、`stolen`)は、`ja` の「(toothの複数形)」のような説明を訳さず、語の意味を書く
  (例: `teeth` → `이, 치아`、`stolen` → `훔친, 도난당한`)。英語を書かない
- 間投詞・略語(`oops`、`lol`)は、韓国語でその場面に言う短い言葉を書く(例: `oops` → `아이고`)
- `ja` の漢語を韓国語の漢字音に置き換えただけの語にしない。韓国語でふだん使う語を選ぶ
  (例: `music` の「楽曲」は `악곡` より `곡`、`friend` の「味方」は `우군` より `자기편`、`case` の「症例」は `증례` より `환자 사례`)
- 古語・まれな意味・専門的すぎる意味は外す。`kaikkiKo` にあっても、学習者がその語で覚えない意味は入れない。
  特に訳の末尾に、珍しい意味を足さない。迷ったら入れない
- 差別語は入れない。**`ja` の先頭に「(卑語)」がある語は、訳全体の先頭に `(비속어) ` を 1 つだけ付ける**
  (例: `damn` → `(비속어) 빌어먹을`)。語義や訳語ごとには付けない(普通の韓国語の訳語まで卑語に見えるため)
- 漢字(한자)・ローマ字を併記しない。`kaikkiKo` の `word` に漢字が付いていても落とす
- 意味の取り違えを防ぐのに要る短い補足だけ `( )` で残してよい(例: `(잡지의) 호`、`(은행) 계좌`)。
  助詞の補足(`…을`)は、付けないと意味が変わるときだけ付ける
- 띄어쓰기と外来語の表記は標準の決まりに従う

## 例文の訳(`exampleTranslation`)

- `exampleEn` に対応した自然な韓国語の訳。英文に無い内容は足さない。見出し語は、訳の先頭の意味で素直に訳す
- **文体**: 基本は 해라체(例: `그녀는 가족과 조용한 저녁을 보내며 행복을 느꼈다.`)。
  依頼・勧誘・質問・案内・許可など、誰かに語りかける文や発言の文は 해요체にする
  (例: `방 번호를 확인하는 동안 여기서 기다려 주세요.`、`도서관 책장에서 좋아하는 책을 고를 수 있어요.`)。
  施設・店・料金の案内も語りかけに入れる(例: `수영장 이용에는 추가 요금이 없어요.`)。
  **합쇼체(`-습니다`、`-십시오`)は使わない**。반말(`-어`、`-니?`、`-자`)も使わない
- **例外**: `ja` の先頭に「(卑語)」がある語の、語りかけや発言の文は 반말にする(丁寧な言い方と卑語の語がそぐわないため)。
  1 人称は `나`・`우리`(例: `Stop fucking about and help us move these boxes.` → `장난 그만 치고 이 상자 옮기는 것 좀 도와줘.`)
- 1 人称は 해라체なら `나`・`우리`、해요체なら `저`・`저희`(相手を含む「私たち」は `우리`)
- `you` は `당신` と訳さない。省いて自然な文にする。`he`・`she`・`they` も、要らなければ省く
- `brother`・`sister` は、話者の性別で語が変わらない `남동생`・`여동생` を基本にする(文脈で年上と分かれば `형`・`누나`・`언니`・`오빠`)
- 人名・地名はハングルで書く(`Tom` → `톰`)。略語(`CD`、`TV`)はそのまま書いてよいが、それ以外の英語を残さない。
  例外として、語そのものを話題にする文(`The teacher explained that tits is a rude word for breasts.`)と、
  打ち込んだ言葉を書く文(`He typed wtf when he saw the bill.`)では、見出し語だけ英語のまま書く
- 約物は半角(`.`、`,`、`?`、`!`)。文末に必ず付ける

## 出力

入力と同じ順で、全語を 1 つの JSON 配列として出力する。JSON 以外の文章は付けない。キーは次の 3 つだけ。

```json
[
  {
    "word": "issue",
    "meaning": "문제, 쟁점 / 발행 / (잡지의) 호 / 발행하다",
    "exampleTranslation": "결정하기 전에 이 문제에 대해 이야기할 필요가 있다."
  }
]
```
