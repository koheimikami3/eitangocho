# 事前生成辞書: 欠けた項目の補完と手直しの指示

英単語帳アプリの自動入力に使う辞書データを作る。入力は、アプリの今の取得経路
(EJDict・kaikki(Wiktionary)・Tatoeba)で引いた結果で、1 語ごとに日本語(`ja`)と
繁体字中国語(`zhHant`)の 2 言語ぶんがある。各項目を確かめ、欠けていれば埋め、
問題があれば直して、指定の JSON で出力する。

利用者は日本語・繁体字の話者で、英検 3 級〜準 1 級あたりの英語を学んでいる。
カードには見出し語・訳・英例文・例文の訳が並ぶ。

## 扱う項目

言語ごとに次の 3 つ。IPA と品詞は扱わない(出力にも含めない)。

- `meaning`: 単語の訳
- `exampleEn`: 英例文
- `exampleTranslation`: 例文の訳

## 判断の基準

### 訳(`meaning`)

- **日本語**: 入力が EJDict(`meaningSource: "ejdict"`)の場合は、語義の中身と表記
  (`〈C〉`、`《+『of』+『名』》`、`『』` など)はそのまま使う。直すのは次の場合だけ
  - **先頭の語義がずれている**: いちばんよく使う意味が先頭に来ていないとき(例: `issue` の先頭が「発行」で、
    「問題」が後ろにある)は、語義(` / ` 区切りの単位)を並べ替える。語義の文言は変えない
  - 古語・まれな語義(`《古》`、`《まれ》` の付いたもの)は末尾に回す
- **日本語で kaikki の訳**(`meaningSource: "kaikki"`、主に句動詞): 訳語の列挙なので、
  よく使う意味が先頭になるよう並べ替える。不自然な訳語・意味のずれた訳語は外す
- **繁体字**: kaikki の訳語の列挙(` / ` 区切り、最大 5 つ)。次の場合に直す
  - よく使う意味が先頭でない → 並べ替える
  - 簡体字が混じっている → その訳語を繁体字にする
  - 性的な俗語・差別語など、単語帳に載せるべきでない訳語 → 外す
  - 台湾で一般的でない言い方 → 台湾で一般的な言い方に替える
- 空のときは埋める。日本語は EJDict の書き方にならい、主な語義を 2〜5 個、` / ` で区切る。
  表記の記号は付けなくてよい。繁体字は訳語を 1〜5 個、` / ` で区切る
- 訳語の数を増やすためだけに足すことはしない

### 英例文(`exampleEn`)

次をすべて満たしていれば、そのまま使う。

- 8〜15 語(カードで 2 行に収まる長さ)
- 見出し語(活用形でもよい)を、訳の先頭の意味で使っている。句動詞はひと続きで含む
- 自然で、日常や学校・仕事の場面で使える文。固有名詞だらけの文、引用の断片、文法的に不完全な文ではない

満たしていなければ、条件を満たす文を新しく書く。短すぎるだけの場合も書き直す
(例: `She looked happy.` は 3 語なので書き直す)。

### 例文の訳(`exampleTranslation`)

- 英例文に対応した自然な訳。英例文を書き直したら、訳も新しく書く
- 英例文がそのままで訳が空、または訳が英文と合っていないときは、訳を書く
- 繁体字は台湾で自然な表現と繁体字で書く

## 出どころ(`source`)

各項目に、次のどれかを付ける。

- `ejdict` / `kaikki` / `tatoeba`: 入力の値をそのまま使った(入力の出どころをそのまま写す)
- `llm_filled`: 入力が空だったので埋めた
- `llm_revised`: 入力の値を直した。並べ替えだけでも `llm_revised` にする

`llm_revised` のときは、`before` に入力の値をそのまま入れ、`reason` に直した理由を日本語で 1 文で書く
(例: 「3 語で短すぎるため書き直した」「先頭の語義が『発行』で、よく使う『問題』が後ろにあったため並べ替えた」)。
`llm_filled` のときも `reason` に何を根拠に埋めたかを 1 文で書く。そのまま使ったときは `before` と `reason` を省く。

例文の入力の出どころは `exampleSource`、訳の出どころは `meaningSource` にある。
例文の訳の出どころは、例文と同じ値を使う。

## 出力

入力と同じ順で、全語を 1 つの JSON 配列として出力する。JSON 以外の文章は付けない。
キーの名前と入れ子は次のとおり。

```json
[
  {
    "word": "issue",
    "ja": {
      "meaning": {
        "value": "〈C〉『問題』,『問題点』 / 〈U〉(印刷物などの)『発行』;…",
        "source": "llm_revised",
        "before": "〈U〉(印刷物などの)『発行』;…",
        "reason": "先頭の語義が『発行』で、よく使う『問題』が後ろにあったため並べ替えた"
      },
      "exampleEn": {
        "value": "We need to talk about this issue before the meeting starts.",
        "source": "llm_revised",
        "before": "This issue is difficult to resolve.",
        "reason": "6 語で短く、場面が分かりにくいため書き直した"
      },
      "exampleTranslation": {
        "value": "会議が始まる前に、この問題について話し合う必要がある。",
        "source": "llm_revised",
        "before": "この問題は解くのが難しい。",
        "reason": "英例文を書き直したため訳も書き直した"
      }
    },
    "zhHant": {
      "meaning": { "value": "問題", "source": "kaikki" },
      "exampleEn": { "value": "…", "source": "tatoeba" },
      "exampleTranslation": { "value": "…", "source": "tatoeba" }
    }
  }
]
```
